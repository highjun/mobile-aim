# MobileAim

스마트폰을 소총 조준경으로 쓰는 Android 앱과 3D 출력 거치대다. 스마트폰을 총 상부 피카티니 레일에 고정한다. 카메라 영상 위 조준점으로 조준한다.

- `app/`: Android 앱
- `hardware/`: 3D 출력 부품. 거치대, 레이저 보어사이터, 레이저 포인터 회전 스위치(참고: [hardware/README.md](hardware/README.md))

## 앱 설치

- [Releases](https://github.com/highjun/mobile-aim/releases/latest) 의 최신 APK 를 스마트폰에 설치한다.
- Android 8.0 이상에서 돈다.
  - 시험한 기기: Galaxy S25 Ultra(Android 16)
- 실행하고 카메라 권한을 허용하면 사격 모드로 시작한다.

## 사용법

1. 장착: 스마트폰을 거치대에 넣고, 거치대를 총 상부 피카티니 레일에 단다.
2. 영점(조준점과 탄착점을 일치시키는 일): 군의 25m 영점 사격 절차를 따른다.
   1. 초기 정렬: 조정 모드에서 화면의 조준점을 레이저 보어사이터(총구에 끼워 총열 방향으로 레이저 점을 쏘는 기구)의 점에 드래그해 맞춘다.
   2. 25m 영점표적지(영점 사격용 격자 표적지)에 사격한다.
   3. 탄착군(여러 발이 맞은 자리의 묶음) 중심이 표적에서 떨어진 칸 수만큼 방향키를 누른다. 1클릭은 영점표적지 한 칸이다.
   4. 탄착군 중심이 표적에 들 때까지 2~3을 되풀이한다.
3. 사격: 사격 모드에서 조준점을 표적에 맞춰 쏜다. 사격 모드에서는 조준점을 옮기는 조작이 잠긴다.

- 영점은 프로파일(총)과 배율마다 따로 저장된다.
- 화면 오른쪽 끝 막대는 총구의 상하 떨림이다.
